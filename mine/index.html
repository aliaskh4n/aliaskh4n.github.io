⛏ VOXEL CRAFT

Воксельный мир на Three.js: физика, разрушение/установка блоков, свой текстовый формат текстур 32×32 с анимацией, редактор моделей и анимаций персонажа, и онлайн-игра с друзьями. Клик — начать игру.

🎨 Быстрый цвет блоков

🧵 Свой текстовый формат текстур (.vtx)

Текстура — это текст, а не картинка:
1) W H — размер сетки (сейчас блоки 32×32)
2) PALETTE, затем символ=HEXцвет (можно несколько через пробел, "." можно сделать .=TRANSPARENT)
3) необязательная строка FPS n — если кадров больше одного, они сменяются n раз в секунду (анимация!)
4) один или несколько блоков FRAME, каждый — ровно H строк по W символов.
Один кадр 32×32 весит около 1 КБ текста — в сотни раз легче PNG.

🧩 Свои модели (воксельные)

Опиши модель JSON-массивом кубиков относительно точки установки. Поле t — тип блока (1 трава, 2 земля, 3 камень, 4 дерево, 5 листва).


🎬 Анимация персонажа (свой клип)

JSON-клип: длительность в секундах и повороты частей тела (armL armR legL legR head torso) в радианах по времени t. Клавиша F проигрывает клип у тебя и показывает его другим игрокам онлайн.


🌐 Онлайн-игра

По умолчанию — канал браузера (BroadcastChannel): открой эту страницу в нескольких вкладках с одинаковым кодом комнаты, и игроки увидят друг друга. Для игры через интернет с других устройств впиши адрес своего WebSocket-сервера (wss://...) вместо кода комнаты.
