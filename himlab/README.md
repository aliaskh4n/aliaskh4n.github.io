# ХимЛаб — виртуальная химическая лаборатория

Открыть: двойной клик по `index.html` (работает офлайн; шрифты Google подгружаются при наличии интернета, иначе используются системные).

## Структура
- `index.html` — готовая собранная страница (всё в одном файле)
- `src/` — исходники:
  - `style.css`, `body.html` — оформление и разметка
  - `data.js` — элементы, реактивы, индикаторы, таблица растворимости
  - `engine.js` — движок реакций (ионы, осадки, газы, нагрев, pH)
  - `lab.js` — лабораторный стол, отрисовка, журнал, практикум
  - `titr.js`, `ptable.js`, `sol.js`, `calc.js`, `gas.js` — остальные разделы
  - `app.js` — вкладки и маршрутизация
- `build.sh` — пересборка `index.html` из `src/` (нужен bash и node для проверки синтаксиса)

Модель упрощённая и не заменяет реальный эксперимент.
